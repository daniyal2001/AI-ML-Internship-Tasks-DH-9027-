# Iris Dataset Exploration & Visualization

## Objective
To explore and visualize the Iris dataset to understand feature relationships and distributions.

## Dataset
- Iris Dataset
- Features: Sepal Length, Sepal Width, Petal Length, Petal Width
- Target: Species

## Steps
- Data loading using pandas
- Data inspection using head(), info(), describe()
- Data visualization using scatter plots, histograms, and box plots

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Key Insights
- Petal features help distinguish species clearly
- Setosa is easily separable
