# House Price Prediction

## Objective
To predict house prices based on property features.

## Dataset
- Kaggle House Price Dataset
- Features: Size, Bedrooms, etc.
- Target: Price

## Steps
- Data preprocessing
- Model training (Linear Regression)
- Model evaluation (MAE, RMSE)

## Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Key Insights
- Size is a major factor in price prediction
